# 安卓应用市场上架材料清单

## 必备材料
- [ ] 软件著作权登记证书（软著）：代码整理 + 申请表，代理 1-3 个月，加急 5-15 个工作日
- [ ] 隐私政策 URL（已就绪：docs/隐私政策.md，需部署到官网或 Gitee Pages 等可访问地址）
- [ ] 用户协议 URL（docs/用户协议.md）
- [ ] 应用图标（512x512 PNG + 各市场适配）、启动图、截图（至少 4 张，建议 1080x1920）
- [ ] 应用描述 + 分类（教育/学习工具）+ 关键词
- [ ] 64 位 APK/AAB（release 构建已支持）

## 国内主流渠道
| 渠道 | 特殊要求 |
|---|---|
| 华为应用市场 | 隐私弹窗合规检测、AGC 账号 |
| 小米应用商店 | 小米开放平台、隐私政策 |
| OPPO 软件商店 | 软著必需 |
| vivo 应用商店 | 软著必需 |
| 应用宝（腾讯） | 软著 + 安全检测 |

## 备案与合规
- 若使用国内服务器/域名：ICP 备案（个人/企业）
- 若接入国内推送：需厂商通道申请（华为/小米/OPPO/vivo）
- 应用加固：腾讯乐固 / 爱加密 / 梆梆（上架前做一次）
- 未成年人保护声明（新规敏感点，已在隐私政策覆盖）

## 海外（可选）
- Google Play：$25 开发者账号 + 数据安全表单 + 隐私政策
