# 手机号登录接入方案（阶段四）

## 前置配置（Supabase 控制台，一次完成）
1. Authentication → Providers → Phone：开启 Phone signup，填短信服务商：
   - 国内推荐：阿里云短信 / 腾讯云短信（经 Twilio 不适用国内，可走 Supabase 自定义 SMS 或 Twilio 国际通道）
   - Supabase 支持 Twilio / Twilio Verify / Vonage / MessageBird；国内可用 Twilio 国际通道或自建 Edge Function 发送
2. 设置验证码模板（`Your code is {{ .Code }}` 已存在于 config.toml）
3. 开启 `enable_confirmations`（短信验证）

## 代码改动点（Login.jsx）
- 注册/登录 Tab 增加"手机号"模式：输入手机号 → `supabase.auth.signInWithOtp({ phone })`
- 收到验证码后 `supabase.auth.verifyOtp({ phone, token })`
- 成功后走既有 `loadProfile()`；新用户需补建 profiles 记录（复用现有 register 逻辑）

## 注意
- 国内手机号需 E.164 格式（+86...）
- 发送频率受限：config.toml `[auth.rate_limit] sms_sent = 30`
- 上架后建议手机号为主登录方式，邮箱保留
