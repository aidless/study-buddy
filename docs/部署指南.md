## 手机 APK 自动更新（Capgo 热更新）

APK 已内置 Capgo 更新组件（@capgo/capacitor-updater）。网页层代码（界面/功能/题库/AI名师）可通过云端热更新，无需重装 APK；原生改动（如屏幕固定）仍需重装。

激活步骤（一次性）：
1. 注册 capgo.app 免费账号 → 创建一个 App（appId 填 com.haolo.studybuddy）→ 复制 API Key。
2. 注入 Key 并重打 APK（Key 只写进构建配置，勿提交 git）：
   set CAPGO_API_KEY=你的Key
   node scripts/capgo-prepare.mjs
   npm run build && npx cap sync android
   cd android && gradlew assembleDebug
3. 上传首个版本到 production 渠道：
   node scripts/capgo-upload.mjs 0.1.0
4. 用户手机安装含 Key 的 APK 后，之后每次更新只需：
   node scripts/capgo-upload.mjs [新版本号]
   手机会在打开 App 时自动拉取新版本并生效。

注意：Capgo 免费版对每月更新次数有限制；上传版本号必须递增且不能重复使用。

### 自建更新服务（Plan B，当前生效方案）

由于 Capgo 云端（api.capgo.app / plugin.capgo.app）在部分网络不可达，已改为自建更新：

- 更新接口：Supabase Edge Function `updates`（协议兼容 App 内置的更新插件）
- 更新包/版本清单：Supabase Storage `updates` 桶（public），国内可达
- 发布新版本（一条命令）：
  set SB_SERVICE_ROLE=<service_role>
  node scripts/publish-update.mjs [版本号]
  脚本自动构建 → 打包 zip → 计算 SHA256 → 上传 zip + latest.json
- 手机端行为：打开 App 自动检查 → 有新版本静默下载 → 下次切后台/启动时生效，无需重装 APK
- 原生层改动（屏幕固定等）仍需重装 APK
