# 部署指南 · 考研督学 App（2026-08-08）

目标：把 App 部署到一个 https 地址，她手机打开 → 添加到主屏，之后每次更新自动生效。

## 前置（只做一次）
1. 构建产物已就绪：`dist/` 目录（已含题库懒加载、Service Worker、新版本提示）。
2. 需要你有的账号之一：Supabase（已有，推荐）/ Vercel / Netlify。
3. AI 名师用的网关密钥：环境变量 HAOLO_DEEPSEEK_EXECUTION_TOKEN 已在本机可用；部署到云端时把它作为 Secrets 配置，**不要写进前端代码**。

## 方案 A（推荐）：Supabase 一个地方搞定（静态站 + Edge Function）
Supabase 已支持静态站点托管，正好和你现有的项目（cfxsyvbxnmvmspklebfa）在一起。

1. 安装 Supabase CLI（本机没有，需装一次）：
   - 官网下载或 `npm i -g supabase`
2. 登录并配置：
   ```
   supabase login
   supabase link --project-ref cfxsyvbxnmvmspklebfa
   ```
3. 部署 AI 名师 Edge Function（supabase/functions/ai-tutor 已写好）：
   ```
   supabase functions deploy ai-tutor
   supabase secrets set AI_TUTOR_API_KEY=<网关密钥> AI_TUTOR_BASE_URL=https://aiapi.youleai.top/v1 AI_TUTOR_MODEL=deepseek-v4-flash
   ```
4. 部署静态站（dist/）：
   ```
   supabase hosting deploy dist --project-ref cfxsyvbxnmvmspklebfa
   ```
   拿到形如 https://<ref>.supabase.app 的地址。
5. 关键：把前端指向 Edge Function。两种方式任选：
   - 部署前构建：`$env:VITE_AI_TUTOR_URL='<函数URL>'` 后 `npm run build`（函数 URL 一般是 https://<ref>.functions.supabase.co/ai-tutor）
   - 或部署后在她手机上首次打开前，无需改代码，直接在控制台把函数路径配上（见方案 C 备注）。

## 方案 B：Vercel / Netlify（静态站，Edge Function 仍用 Supabase）
1. 项目根已含 `vercel.json` / `netlify.toml`（SPA 重写 + SW 缓存头已配好）。
2. Vercel：登录 vercel.com → New Project → 导入本仓库/文件夹 → 输出目录选 `dist` → Deploy。
   Netlify：登录 → Add new site → Deploy manually → 拖入 `dist/` 文件夹。
3. 得到 https 地址，给她。

## 方案 C：手机使用（两种方案通用）
1. 她手机浏览器打开 https 地址 → 注册/登录。
2. iOS：Safari → 分享 → 添加到主屏幕；Android：Chrome 菜单 → 添加到主屏幕。
3. 之后**每次更新**：你在云端重新部署 dist → 她打开 App 会看到顶部"发现新版本 → 更新"，点一下即刷新到最新，无需重装。
4. 系统通知（打卡提醒）：需在 App 里"更多工具 → 开启提醒"授权；真 Web Push 需额外接推送服务器，当前为本地提醒。

## 更新流程（日常）
- 改代码 → `npm run build` → 重新部署 dist（方案 A 一条命令；方案 B 推仓库/拖文件夹）。
- Edge Function 改动 → `supabase functions deploy ai-tutor`。
- 她端零操作。
