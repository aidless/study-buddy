## 面试时怎么讲（90 秒）

1. **用户**：正在备考的人，计划大、完成感弱、容易被催促加重焦虑。
2. **做法**：把 11408 课纲变成今日 3 件事；用番茄钟/热力图把“完成”变可见；用树洞/一句话降低情绪负担；默认本地，云端可选。
3. **证据**：内测 N 人、X/10 无提示完成首个任务、Y/10 回访；3 个摩擦点及修法。
4. **边界**：不是心理治疗；AI 名师内测；Android/小程序未公开。
5. **下一步**：把激活率从 X 提到 Y，或把回访率作为唯一北极星。
