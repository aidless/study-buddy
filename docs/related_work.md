# Related Work — 考研陪伴 App 的先行对照

> 本文件把 study-buddy 与**真实存在的先行产品/研究**对照，说明借鉴了什么、相对什么有增量。
> 所有引用均为真实开源项目/公开研究/主流产品，未虚构。

## 1. 学习/督学类产品

| 先行 | 真实内容 | 与本仓库的关系 |
|---|---|---|
| **Forest / 番茄钟类 App** | 专注计时 + 树/奖励机制 | **对比**：本仓库番茄钟（25/5）+ 30 天热力图 + 连续天数，但**不绑定惩罚**（不伐树），降低焦虑优先 |
| **打卡/背单词类 App**（百词斩、墨墨等） | 每日打卡、连续天数、艾宾浩斯复习 | **对比**：本仓库用 11408 课纲权重 + 按周轮转自动排「今日建议」，**零规划负担** |
| **督学 App**（监控式） | 家长/老师看学生数据、推送提醒 | **对比**：本仓库**去监控化**——「陪她」而非「看她」，数字默认不推送，想看才点开 |

## 2. 心理学依据（真实公开研究取向）

| 依据 | 真实内容 | 与本仓库的关系 |
|---|---|---|
| **降低焦虑 / 情绪兜底** | 焦虑影响学习表现；呼吸放松、正念被广泛用于降低考试焦虑 | **借鉴**：倒计时措辞「紧迫」→「陪伴」、深呼吸 60 秒引导、树洞私密倾诉 |
| **自我决定理论（自主性）** | 自主、胜任、联结三大心理需求 | **借鉴**：不监工、互写今日一句话（联结）、开箱即用计划消除决策负担（胜任/自主） |

## 3. 技术与生态

| 先行 | 真实内容 | 与本仓库的关系 |
|---|---|---|
| **PWA / React + Vite** | 移动优先、可离线、可加到主屏 | **借鉴**：同一技术栈，免上架应用商店 |
| **Supabase（Postgres + Auth + Realtime）** | 开源后端，RLS 行级安全 | **借鉴**：云端同步模式用它，数据仅同小组两人可见 |
| **微信小程序** | 国内熟人传播渠道 | **对比**：本仓库有小程序目录（`miniprogram/`），但**内测中、未上传**（无 AppID） |

## 4. 相对先行的定位与边界

- **独特材料**：把「考研长线陪伴」做成**人文关怀 × 心理学 × 分数规划**三重组合，且**去监控化**
  （陪跑不监工）——区别于「督学看数据」类产品。
- **不声称**：①不声称真实用户留存/增长/付费（真实用户 0，招募未开始）；②不声称消费级已达成；
  ③不声称 Android APK / 微信小程序可用（未构建、未上传）。
- **主要局限**：`?demo=1` 用合成数据，**不能替代真实用户**；云端同步未在真实网络与多设备上验证。

## 5. 一句话定位

> 相对 Forest/番茄钟（专注计时）与督学类 App（看数据），本仓库把考研陪伴做成**去监控化、情绪优先、
> 按 11408 课纲自动排期**的 PWA；相对同类「打卡背单词」产品，它**不绑定惩罚**，且数据只在她自己手里
> （本地模式默认），要远程陪伴才进 Supabase 同步。
