# 推送通知接入方案（阶段四）

## 目标
督学场景"打卡提醒 / 督学送鼓励"需要系统级推送。当前仅本地 Notification（App 打开时触发），不满足离线推送。

## 架构（国内）
| 通道 | 场景 | 说明 |
|---|---|---|
| 华为推送 | 华为设备 | 需华为开发者账号 + AGC 配置 |
| 小米推送 | 小米设备 | 小米开放平台 |
| OPPO 推送 | OPPO 设备 | OPPO 开放平台 |
| vivo 推送 | vivo 设备 | vivo 开放平台 |
| FCM | 海外/兜底 | 可选 |

## 实现
1. 客户端：@capacitor/push-notifications 统一 API，注册拿 device token，上报到 `devices` 表（couple_id 关联）
2. 服务端：Supabase Edge Function `push`（Webhook 或 DB trigger 触发），按设备厂商路由到对应推送 API
3. 触发点：每日 20:00 未打卡提醒、督学送鼓励/复活卡、自测报告生成
4. 权限：Android 13+ 需运行时通知权限（App 内"开启提醒"已预留）

## 注意
- 国内厂商通道需要各平台审核（应用名、包名、签名一致）
- 通知文案合规：不得含诱导、虚假承诺
