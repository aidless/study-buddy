# 10 人内测包（D11–12）

目标不是“收集夸奖”，而是拿到 3 条能改的摩擦点。**不要伪造用户数或反馈**；没有发生的就写 0。

## 招募（10 人）

来源优先级：

1. 正在备考的朋友/同学（最快，也最愿意说真话）
2. 考研群/小红书/即刻（发“内测 10 个名额，免注册，帮我看 3 分钟”）
3. 之前用过类似打卡 App 的人（能对比）

招募话术：

> 我在做一个考研长线陪伴的小工具，不用注册、数据默认在手机本地。想找 10 个正在备考的人试用 3 次，每次 5 分钟；不会公开你的任何记录。愿意的话回我一句“可以”，我发链接。

## 知情与隐私

- 不录屏、不录音，除非对方明确同意；默认只记文字笔记。
- 笔记用编号（U01…U10），不写真实姓名、学校、群名。
- 不收集树洞/悄悄话内容；只看他们是否找到入口、是否卡住。
- 对方可以随时退出，删除本地数据即可。

## 三次会话脚本

### 第 1 次：第一次打开（5 分钟）

只说一句：“你随便用，遇到不知道点哪就告诉我。”然后**3 分钟内不帮忙**。

记录：

- 从打开到第一次点“开始/下一步”用了多久？
- 有没有读完首屏就知道这是做什么的？
- 3 步引导是否卡住？哪一步想跳过？
- 第一个任务是否勾选成功？

### 第 2 次：完成一个真实任务（5 分钟）

任务：“找到今天的 3 件事，完成一件；再开一个番茄钟。”

记录：

- 找到今日建议用了多久？
- 勾选后有没有看到完成率/连续天数变化？
- 番茄钟的开始/暂停/结束是否清楚？
- 有没有误触“退出/删除”？

### 第 3 次：两天后回访（3 分钟）

- 这两天有没有主动打开？为什么？
- 打卡/热力图有没有看懂？
- 最想删掉/最想加的一个东西是什么？
- 愿不愿意继续用一周？

## 通过标准（内测版）

- **7/10** 能在无提示下完成第一件任务；
- **5/10** 两天后仍愿意继续用；
- 收集到 **≥3 条**可复现的摩擦点，并修掉其中前 3 条；
- 不追求留存曲线漂亮；先追求“陌生人能用”。

## 现有可用信号

- 首次动作：`localStorage.dx_first_action`（事件名 + 时间）
- 关键事件：`app_open` / `task_done` / `focus_done` / `checkin` / `feedback_open` / `feedback_copy` / `onboarding_complete`
- 若宿主装了 Plausible/Umami，事件会转发；默认不联网。
- 本地模式没有服务端留存；D1/D7 只能靠回访或让用户自己说。

## 不要做的事

- 不要让 10 个人互相看数据（这是双人产品，不是社群）。
- 不要用“你看别人都在用”施压；这个产品的原则是陪跑不监工。
- 不要把内测反馈写成“用户量”“增长率”；没有统计口径就不写。
