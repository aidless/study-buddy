# SelfEvolve Agent：最小可信自进化闭环（方案 C 实现）

版本：0.1.0（2026-08-06）

这是一个**真正可运行**的受限自进化 Agent 骨架，按既定的"受限更新、外部验证、分区数据、成本校正、可回滚、负结果完整报告"路线实现：

```text
observe -> diagnose -> propose -> evaluate -> promote/reject
```

当前实现把"自进化"定义为：候选技能来自 Agent 自身的失败反思，但必须通过独立验证任务 + 非回归门的预算匹配检验，才能进入版本化技能库并影响后续行为。控制面、任务库、账本均不可由候选修改。

## 架构

| 文件 | 职责 |
| --- | --- |
| `control_plane.json` | 冻结配置：端点、采样、预算、晋升门、Curator 规则 |
| `task_bank.json` | 冻结任务库：20 个 legacy acquisition + 4 validation + 4 sealed |
| `agent/config.py` | 控制面加载与 SHA-256 指纹 |
| `agent/ledger.py` | 追加式哈希链账本（篡改可检测） |
| `agent/tools.py` | 沙箱工具 + 权限 broker（只能写 target.py，无 shell/网络） |
| `agent/llm_client.py` | llama.cpp OpenAI 兼容客户端（`http://127.0.0.1:8080/v1`） |
| `agent/runner.py` | 单任务执行器（base / placebo / skills 三策略） |
| `agent/skills.py` | 技能库、Curator、冻结检索策略、安慰剂生成 |
| `agent/gate.py` | 双 oracle 晋升门 + 证据分型（bug_discriminating / regression_only） |
| `agent/cycle.py` | 端到端闭环编排器（acquire → diagnose → curate → validate → sealed → report） |
| `prompts/*.txt` | 冻结提示词（Agent 规则、技能诊断指令） |
| `tests/` | 账本篡改、晋升门、Curator、沙箱的单元测试 |

## 运行

前置条件：llama.cpp llama-server 已在 `http://127.0.0.1:8080/v1` 运行（模型 `lfm2.5-2.6b`，工具调用已验证）。

```powershell
# 最小闭环烟测（6 acquisition + 4 validation + 4 sealed，约几分钟）
powershell -ExecutionPolicy Bypass -File .\run_smoke.ps1

# 完整闭环（20 acquisition）
python -m agent.cycle --phase all

# 分相位执行（可断点续跑）
python -m agent.cycle --phase acquire
python -m agent.cycle --phase diagnose
python -m agent.cycle --phase validate
python -m agent.cycle --phase sealed
python -m agent.cycle --phase report

# 单元测试（不调用模型）
python -m unittest discover -s tests -v
```

状态与产物都在 `state/`：

- `ledger.jsonl`：追加式哈希链账本，`agent.ledger.Ledger.verify` 可检测篡改；
- `acquire_results.json`：acquisition 运行结果（含预算向量）；
- `candidates_proposed.json`：诊断阶段产出的候选技能；
- `skills_library.json`：晋升后的持久技能库（跨轮次保留，best_so_far 语义）；
- `cycle_report.json`：本轮完整报告。

## 证据诚实性（强制声明）

当前 28 题的验证与密封任务都属于**工程烟测**：

- 20 个 legacy 任务是规格已知的回归夹具，只支持"规格实现检查"；
- 新增的 validation/sealed 任务只证明闭环机制能跑通，样本量不足以支撑泛化或"递归自我改进"主张；
- 任何晋升都必须满足：隐藏测试通过 + public 不回归 + 证据可区分目标缺陷（buggy 源上 hidden 必须失败）；
- 报告中出现的"提升"只描述本机、本任务库、本策略的差异，不是能力增长的证据。

要到"能发表的自进化证据"，下一步（方案 B）需要：规则族隔离的更大任务库、多轮重复采样、预注册的 delta_min 与错误预算、独立统计检验。

## 安全与治理

- 候选 Agent 的工具集固定：read_file / write_file / run_public_tests / submit_fix；
- 代码禁止 subprocess、os.system、socket、importlib、open()、pathlib、shutil；
- 隐藏测试只由 harness 执行，永不返回给模型；
- Curator 拒绝包含"修改测试/账本/控制面/晋升门/绕过"的候选技能；
- 晋升需同时满足目标行为 oracle 与非回归 oracle；被拒绝的候选保留在账本；
- `skills_library.json` 只有 promoted 技能，新候选被拒时旧库继续作为 incumbent（best_so_far）。
