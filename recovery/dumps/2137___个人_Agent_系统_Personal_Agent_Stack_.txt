# 个人 Agent 系统（Personal Agent Stack）

目标：以你自己为数据源、以记忆为身份、以评测为门槛、以控制平面为边界的个人模型系统。

## 当前已接入

- 模型：LFM2.5-2.6B（Q4_K_M），由 llama.cpp 服务在 `http://127.0.0.1:8080/v1`（65K 上下文、q8 KV 缓存）
- Agent 框架：Hermes Agent v0.20.0，provider `lfm25`，默认模型 `lfm2.5-2.6b`
  - 配置：`C:\Users\Administrator\AppData\Local\hermes\config.yaml`（已备份为 `config.yaml.bak-personalagent-20260806`）
  - 冒烟测试通过：`hermes -z "Reply with exactly: LFM_OK"` → `LFM_OK`
- Hermes 自带能力：会话日志（trajectory）、记忆（`memory` toolset）、技能（skills）、用户画像、cron

## 目录结构

```
personal-agent/
├── README.md
├── events/            # 事件流（JSONL，只追加）：从 Hermes 会话日志收集
├── memory/
│   ├── episodic/      # 情景记忆：原始事件归档
│   ├── semantic.md    # 语义记忆：每周压缩出的“关于你的事实”
│   └── procedural.md  # 程序性记忆：你希望事情怎么做（规则/模板）
├── data/
│   └── corrections.jsonl  # 纠错数据：唯一允许进训练集的样本
├── eval/
│   ├── personal_eval.json  # 个人回归评测集（llm-lab 风格）
│   └── run_eval.py         # 评测运行器，输出证据包
└── scripts/
    ├── collect_events.py   # Hermes 会话日志 → events/
    ├── compact_memory.py   # 事件 → 语义记忆（每周跑一次）
    └── weekly_review.py    # 周复盘：统计 + 候选样本
```

## 数据铁律

只有三类数据可以进入 `data/corrections.jsonl`（训练候选）：

1. 你纠正过的回答（用户改写 / 否定）
2. 教师模型重写的高质量版本（周复盘时用强模型生成）
3. 明确标注的失败案例（负样本）

agent 自己未经修改的输出只属于 `events/`，不属于训练数据。

## 每周循环

```powershell
# 1. 收集本周 Hermes 会话
python scripts/collect_events.py

# 2. 压缩语义记忆（调用本地模型）
python scripts/compact_memory.py

# 3. 周复盘统计
python scripts/weekly_review.py

# 4. 跑个人评测（回归门槛）
python eval/run_eval.py
```

规则：
- 每周挑 5–10 条高价值样本写进 `data/corrections.jsonl`
- 发现 agent 犯错 → 立刻加一条 eval 测试（`eval/personal_eval.json`）
- 每月才考虑微调（LoRA），且必须旧版影子运行一周、评测通过才换

## 评测格式（llm-lab 风格）

`eval/personal_eval.json` 的每个任务包含：

```json
{
  "id": "p01_tool_weather",
  "category": "tool_use",
  "prompt": "...",
  "tools": [{"type": "function", "function": {...}}],
  "verifier": {"type": "tool_call", "name": "get_weather"},
  "weight": 2,
  "tags": ["must-pass"]
}
```

verifier 类型：`tool_call` / `contains` / `refusal` / `length`。
每次运行输出证据包到 `eval/outputs/run_<时间戳>/`：`outputs.jsonl`、`verdicts.jsonl`、`report.json`、`manifest.json`。

## 换模型不换自我

记忆、评测、纠错数据、控制规则都独立于模型权重。以后换更强的开源模型时，只需要改 `lfm25` provider 的 base_url / model，其余原样继承。
