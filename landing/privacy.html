数据说明

最后更新：2026-10-25 · 内测版

督学默认把数据留在你自己的设备上。这份说明写清楚：我们存什么、存在哪、怎么删，以及哪些事情我们不做。

1. 我们存什么

  • 昵称、角色（学员 / 督学）、邀请码；
  • 你主动录入的内容：任务、专注记录、打卡、自测、倒计时、目标分、阶段目标、今日一句话、树洞、悄悄话；
  • 运行所需的最小本地状态，例如是否已看过某条里程碑提示。

我们不收集通讯录、精确位置、广告标识符，也不读取你设备上的其他文件。

2. 数据存在哪

本地模式（默认）：上述数据只存在当前浏览器的 localStorage 里。它不会上传到我们的服务器；清除浏览器数据、换浏览器或换设备后无法恢复。

云端同步（可选）：如果你自行配置 Supabase，数据会写入你自己的 Supabase 项目（Postgres + Auth + Storage）。表启用了行级安全（RLS），只有同一小组的两个人能读取对应数据。Supabase 的可用性、备份与计费由你和 Supabase 的协议决定。

3. 我们不做什么

  • 不卖数据，不做广告画像；
  • 不把数据用于训练模型；
  • 不默认接入第三方分析。若部署者在页面里启用 Plausible / Umami 等访问统计，会记录事件名、页面路径与匿名设备信息，不包含任务、树洞或悄悄话内容；当前版本默认未接入。

4. 怎么删除

  • 本地模式：清除浏览器站点数据即可；也可以在应用内删除任务、打卡等记录。
  • 云端模式：在 Supabase 控制台删除对应行、用户或整个项目。当前内测版没有一键注销入口；需要协助可以在 GitHub Issues 里提。

5. 情绪支持不是医疗

树洞、60 秒呼吸和今日一句话是日常支持工具，不是心理治疗或医疗建议，也不能替代专业帮助。如果你或你关心的人持续情绪低落、出现伤害自己的想法，请联系当地的专业心理支持或急救服务。

6. 年龄

本产品面向备考的成年人及高中生，不面向 14 岁以下儿童。若你是未成年人，请在监护人知情的情况下使用。

7. 联系

数据相关问题、删除协助或安全报告：GitHub Issues。请不要在公开 issue 里粘贴真实的私人内容。
